# Handoff

The project began as a small personal-page experiment and gradually became a more complete static “About Me” site. Early work established the page structure, README/project housekeeping, basic layouts, favourites and hobby content, plus several visual/theme iterations (including a few tests and reversions).

The middle of the history focused on refining the navigation and its cloud/gradient effects, cleaning up the code, adding a library page/teaser, and introducing a project plan. Content was then reshaped into travel, postcard-drawing and sports areas, with images and cards adjusted over time; a small memory game was also added.

The latest work concentrated on sports/football card details and team information, followed by experiments with colour modes. Those mode changes were partly reverted, leaving the most recent state centred on a final football-card update. Overall, the history is an iterative visual/content build with occasional experiments, tests and rollbacks rather than a single linear redesign.
