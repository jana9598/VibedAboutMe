# AGENTS.md — Project Rules

Static personal website (university project). HTML5, CSS3, vanilla JS only. No frameworks, libraries, npm or build tools. English throughout. Must work by opening the pages directly.

## Stack & layout
- Site root is `docs/`. Entry pages: `docs/index.html`, `docs/library.html`, `docs/game.html`.
- Shared assets: `docs/css/style.css` and `docs/js/main.js`. There is no root `index.html`.
- No build, test or lint commands. Verify by opening the three pages directly (file://) and checking 360 / 768 / 1280 px.
- `PLAN.md` records intended changes and may lag behind the code; trust the code.

## House rules
1. Read existing code first and follow its patterns. Make small, targeted changes only.
2. Reuse existing classes and CSS variables before creating new ones.
3. HTML: one `<h1>`, semantic elements, 4-space indent, section comments, British English.
4. CSS: `kebab-case` classes, all colours/spacing via variables, Flexbox/Grid, mobile-first.
5. JS: vanilla only, `const`/`let` (never `var`), `camelCase`, shared file loaded with `defer`, 2-space indent.
6. Accessibility: `alt` on images, `aria-label` on icon links, visible focus, WCAG AA contrast.
7. File names lowercase `kebab-case`; CSS/JS in separate files.
8. Ask when unclear; report what changed, which files, what to test.

## Never do
- No frameworks, libraries, npm or build tools.
- No inline CSS/JS (no `<style>`, no `onclick`).
- No loose hex colours, no `!important` (except the existing `.hidden` utility), no `transition: all`.
- No `var`, no float/table layout, no global variables.
- No `console.log` in finished code.
- No unrequested changes, invented content or extra features.

## Repo-specific gotchas
- `docs/js/main.js` is shared by all pages inside one `DOMContentLoaded` handler; init functions return early when their elements are absent. Do not split it or add globals.
- Navigation and theme-switcher markup is duplicated in all three pages; update all of them together.
- Set `is-active` plus `aria-current="page"` on exactly the current page's nav link (past bug: `index.html` marked Library as current).
- Theme switcher stores `data-theme` on `<html>`; valid values are `rainbow`, `night`, `garden`. Persist under localStorage key `jana-theme`; default to `rainbow` for missing/invalid values and ignore storage errors. Keep it in normal flow so it scrolls away.
- Football team identity colours use dedicated `--team-*` tokens and must not be themed; only `--team-own-soft` changes per theme.
- Mobile breakpoint is 620 px; also honour `prefers-reduced-motion`.
- Image filenames keep spaces and mixed-case extensions (e.g. `wales (2).jpg`, `HSV.png`); preserve exact names/encoding.
- Library tabs use hash routing (default `books`) with arrow/Home/End keyboard navigation; the memory-game board is generated by JS into an empty `ul`.
